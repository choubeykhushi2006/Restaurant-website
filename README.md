# Bite & Brew — Frontend-only React Website

A complete frontend-only digital food menu built with React + Vite.

## Features
- Home page
- Explore menu
- Search food
- Category filters
- Individual category pages
- Food cards
- Add to cart
- Quantity controls
- Cart drawer
- Responsive mobile design
- QR-code concept section
- No backend or database

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Important
The food images currently use external Unsplash image URLs. The site is frontend-only, so the checkout button is a demo.
